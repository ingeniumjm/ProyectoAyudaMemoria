🚀 Configuración Inicial de Git

Sigue este paso a paso para descargar el repositorio ProyectoAyudaMemoria y ubicarte en tu rama de trabajo asignada de forma correcta.

Pasos para empezar a trabajar

  1. 1. Crear una carpeta en tu computadora Crea una carpeta vacía en cualquier ubicación (ej. Escritorio) con el nombre del proyecto.
  2. 2. Abrir la carpeta en Visual Studio Code Abre VS Code, ve a Archivo > Abrir carpeta y selecciona la carpeta vacía que acabas de crear.
  3. 3. Abrir la terminal integrada Abre la terminal dentro de VS Code presionando las teclas Ctrl + Ñ (o ve a Terminal > Nueva terminal en el menú superior).
  4. 4. Clonar el repositorio oficial Copia el siguiente comando haciendo clic en el botón y ejecútalo en tu terminal para descargar los archivos:
    git clone https://github.com/ingeniumjm/ProyectoAyudaMemoria.git .
    * Nota: El punto al final es obligatorio para evitar carpetas duplicadas.
  5. 5. Sincronizar las ramas del servidor Trae la información de las ramas que ya fueron creadas por el administrador:
    git fetch --all
  6. 6. Cambiarte a TU rama asignada Reemplaza la palabra tu-nombre por el nombre exacto de la rama que te asignaron y ejecuta el comando:
    git checkout tu-nombre

📤 Cómo subir tus avances diariamente

Cuando termines tus tareas y quieras guardar los cambios en GitHub dentro de tu rama, ejecuta estos 3 comandos uno por uno:

git add .
git commit -m "Mis avances del dia"
git push
